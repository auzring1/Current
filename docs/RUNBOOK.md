# Runbook

Status: skeleton. This is filled in as each phase lands; sections below show what will be covered.

## Installation (Phase 1)
- Host requirements (Docker Engine 24+, Compose v2, 2 vCPU / 4 GB RAM / 40 GB for ~2k devices; sizing table for 10k in Phase 6).
- DNS names: GUI hostname (443) and agent gateway hostname (8443, can be the same name).
- Firewall rules: inbound 443 and 8443 to the server; outbound from endpoints to 8443 and to vendor download hosts.
- **TLS-inspecting proxies must exempt the gateway host** (mTLS cannot be inspected).
- Secrets: `server_master_key` (KEK, 32 random bytes) and `postgres_password` as Docker secrets; generated by `scripts/init-secrets.sh`.
- `docker compose up -d`, then complete first-run setup using the one-time setup token from `docker compose logs server`.
- GUI TLS modes: public ACME, Caddy internal CA (distribute root via GPO), or admin-provided certificate.

## Agent deployment (Phase 1; MSI in Phase 5)
- Create an enrollment token, copy the `AURZ1.…` bundle.
- Install: `msiexec /i auzring-agent.msi /qn ENROLLMENT_BUNDLE="AURZ1...." [ALLOWED_JOBS=...]`.
- GPO, Intune, and RMM examples.

## Day-2 operations
- Upgrades: back up, then pull the new image; migrations run automatically under an advisory lock.
- Backup and restore (`auzring-server backup` / `restore`, encrypted with age). Test restores quarterly.
- Certificate and key rotation: gateway certificate (automatic), issuing CA (root unlock), job-signing key (root unlock).
- Revoking a device; revoking a signing key (incident).
- Audit-log verification and SIEM forwarding.

## Incident response
- Suspected server compromise: isolate host, rotate KEK, revoke job-signing key (root-signed revocation reaches agents on reconnect), review audit log, re-issue.
- Suspected endpoint compromise: revoke device; re-enroll after rebuild.

## Troubleshooting
- Agent logs: `C:\ProgramData\Auzring\logs\`; Event Log source `Auzring Agent`.
- Common failures: clock skew, proxy inspection, pending approval, policy-ceiling rejections.
